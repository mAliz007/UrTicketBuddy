# @urticketbuddy/web

Frontend single-page application for UrTicketBuddy.

## Tech Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS

## Port

- Runs locally on `http://localhost:5173`

## Directory Structure

- `src/features/<feature>`: Feature modules (auth, events, seat-map, checkout, etc.)
- `src/components/ui`: Common shared UI primitives
- `src/lib`: Client-side utilities and API client
